#Contenido de la Carpeta

Esta carpeta contiene toda la documentación técnica, administrativa y académica desarrollada durante la ejecución del proyecto integrador del vehículo autónomo. Aquí se almacenan los archivos relacionados con la planeación, seguimiento, desarrollo, validación y presentación final del sistema, permitiendo mantener un control organizado de la información generada a lo largo del semestre.

Acta de Constitución

Documento oficial que formaliza el inicio del proyecto. En este archivo se definen los objetivos generales y específicos, el alcance del sistema, la problemática a resolver, la metodología de trabajo, los recursos disponibles y la distribución de roles dentro del equipo de desarrollo. Además, incluye las aprobaciones correspondientes por parte de docentes y asesores encargados del seguimiento del proyecto.

Bitácoras

Registro cronológico y detallado del avance semanal del proyecto. Cada bitácora documenta las actividades realizadas durante las sesiones de trabajo, las modificaciones implementadas tanto en hardware como en software, las pruebas ejecutadas, los inconvenientes encontrados y las soluciones aplicadas. También se incluyen observaciones técnicas, acuerdos del equipo y compromisos establecidos para las siguientes fases del desarrollo.

Informes

Carpeta destinada al almacenamiento de informes de avance e informe final del proyecto. En estos documentos se describe el desarrollo técnico y metodológico del vehículo autónomo, incluyendo el diseño mecánico, electrónico y de programación. Asimismo, se presentan análisis de resultados, validaciones realizadas, conclusiones obtenidas y recomendaciones para futuras mejoras del sistema.

Manual de Usuario

Guía de operación diseñada para facilitar el uso correcto del vehículo autónomo. Este manual explica paso a paso el procedimiento de encendido, configuración inicial, conexión de componentes, ejecución del sistema autónomo y monitoreo del funcionamiento general. También contiene instrucciones para la calibración de sensores, solución de problemas comunes, recomendaciones de seguridad y mantenimiento preventivo del robot.

Presentaciones

Contiene las diapositivas utilizadas durante las exposiciones y sustentaciones académicas del proyecto. Estas presentaciones resumen de forma visual y técnica los avances realizados, la arquitectura del sistema, el funcionamiento del vehículo autónomo, las pruebas efectuadas y los resultados obtenidos durante el desarrollo del proyecto integrador.

Artículo Publicable

Documento redactado bajo formato académico con el propósito de presentar de manera formal el desarrollo del proyecto. Incluye introducción, planteamiento del problema, metodología implementada, resultados experimentales, análisis técnico y conclusiones finales. Este archivo está orientado a la divulgación académica y puede ser utilizado como base para publicaciones o eventos institucionales.

Matriz de Control de Documentos

Archivo utilizado para llevar el control y seguimiento de todos los documentos generados durante el proyecto. En esta matriz se registra información como nombre del documento, versión, fecha de modificación, responsable, estado de aprobación y observaciones correspondientes, garantizando una adecuada gestión documental.

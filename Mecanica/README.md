# Mecánica — C.A.L.V.O.S.

Esta carpeta contiene todos los archivos de diseño mecánico del robot móvil autónomo C.A.L.V.O.S. (Control Autónomo Logístico Vehicular Optimizado de Suministros), desarrollado por el Grupo 4 del Semestre Integrador de la Universidad Tecnológica de Pereira — Ingeniería Mecatrónica 2026.


## Contenido
- **STL/** — Archivos listos para imprimir en impresora 3D
- **Fusion360/** — Archivos editables del diseño (.f3d)
- **Planos/** — Planos técnicos en PDF
